# Nimus_music_player_Grischenko
Простой музыкальный плеер, способный проигрывать музыку с любой папки на вашем компьютере. Создан он, на языке программирования python с использованием библиотек: pygame, os и tkinter.
# ВАЖНО!
Для корректной работы плеера вам нужно будет установить через pip (если у вас не установлены) библиотеку pygame.
# Использование
1. Вверху плеера есть кнопка выбора папки, вы выбираете нужную и плеер сам находит треки.
2. Вы можете менять громкость передвигая ползунок, находящийся справа снизу.
3. Есть возможность паузы, продолжения, отсановки и повтора воспроизведения музыки.
4. Имеются фунции перелистывания треков по соотвествующим кнопкам.
